Nothing you type leaves your Mac.

      

        

          The model is Qwen2.5-Coder, served by llama.cpp on 127.0.0.1 and kept running
          by launchd. Your screen, history and keystrokes go to that process and nowhere else. There is
          no account and no API key.
        

        

          A menu bar item shows the loaded model, the median latency and the last ten suggestions.
          wisp pause turns suggestions off until you say wisp resume.
        

      

      
    
        
  • After a command wisp predicts the next one while the prompt is still empty.
    • 
        
  • While you type it completes the line after a 60 ms pause, and keeps the suggestion as long as you type along with it.
    • 
        
  • To accept press →, End or Ctrl F, the keys zsh-autosuggestions already taught your hands.

Install

      
macOS on Apple Silicon, zsh with zsh-autosuggestions, and a Rust toolchain. Screen reading needs WezTerm; other terminals get history, files and git.

      
    
        
  1. 
          
    Get llama.cpp and download the model once (1.65 GB). Stop it with Ctrl-C when it says server is listening.
    
          
    brew install llama.cpp && llama-server --fim-qwen-1.5b-default
    
        
    2. 
        
  2. 
          
    Build wisp and keep llama-server running at login.
    
          
    git clone https://github.com/micovi/wisp && cd wisp && cargo install --path . && ./scripts/install-llama-service.sh
    
        
    3. 
        
  3. 
          
    Load the plugin after zsh-autosuggestions, then open a new tab.
    
          
    echo 'eval "$(wisp init zsh)"' >> ~/.zshrc
